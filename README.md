# NH-ANP: nieuwsdienst Zaanstreek (ZANP)

Een nieuwsdienst die elk uur bronnen van gemeente, media en instellingen ophaalt,
beoordeelt en toont op een website. Alles draait op GitHub Actions.

- Hoe het in elkaar zit: [`docs/ARCHITECTUUR.md`](docs/ARCHITECTUUR.md)
- Welke bronnen er zijn en hoe je er een toevoegt: [`gemeenten/README.md`](gemeenten/README.md)
- Wat er wanneer is gebouwd: [`docs/PLAN.md`](docs/PLAN.md)
- Code ontwikkelen: `cd kern && npm install && npm test`
